### 🔬 Currently Working On

**[MRSI Data Normalization Tool](https://github.com/ibrahim-parvez/MRSI_Data_Normalization_Tool)** · *Research Software Engineer, McMaster University*
A Python desktop application (PyQt6) that automates the processing and standardization of raw mass-spectrometer data for the MRSI research group.
- **Workflow automation:** data extraction and transformation with `openpyxl` replaces manual data entry, eliminating transcription errors and saving several hours of work per dataset
- **Testing & iteration:** unit tests for edge cases to protect data fidelity, plus new features driven by direct lab feedback (including lenient, substring-based matching for reference materials with variable suffixes)

**[mrsi.mcmaster.ca](https://mrsi.mcmaster.ca)** · *Research group website*
A rebuild of the group's site with a clean, modern design and a custom built-in editor written in PHP. Staff can change text, images, page sections, and the site chatbot directly on the page, much like WordPress but lightweight and custom-built.

**Rookery** · *Capstone team project*
A web platform for creating, sharing, and playing chess variants, with a no-code variant editor, a shared TypeScript rules engine, and real-time multiplayer. My part is the frontend: I'm building the UI in **Next.js** and **React** and integrating it with the rules engine and backend services.

**GPU Heat Diffusion Simulator** · *Personal project, in progress*
A 2D heat-equation solver written in **CUDA C++** that uses shared-memory tiling. I'm benchmarking it against a CPU baseline for speedup and memory bandwidth across grid sizes.
